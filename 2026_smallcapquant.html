小盘股效应 (Small Cap Effect)

Fama-French 三因子模型中的 SMB（Small Minus Big）因子表明：小市值公司的长期收益往往高于大市值公司。 这一现象在 A 股市场尤为明显。本系统聚焦总市值 8-100 亿元的小盘股，通过 LLM 评分排除垃圾股， 筛选出具有成长潜力的优质小盘。

股票池条件：
8亿 ≤ 总市值 ≤ ~100亿
总市值/流通市值 ≤ 4.0
20日均成交额 ≥ 1200万
按市值升序取前 100 只
🤖

LLM 辅助投资分析

传统量化因子（PE、ROE 等）只能捕获结构化数据信号。Google Gemini 大模型可以理解新闻公告、行业政策、市场情绪等非结构化信息。 系统将每只股票的 40+ 个因子数据构建成 Prompt，让 Gemini 在 5 个维度打分，实现"定量+定性"融合分析。

五维评分 (各 0-10 分)：
基本面 × 0.20 + 催化剂 × 0.25
+ 风险 × 0.30 + 资金面 × 0.10
+ 概念热度 × 0.15 = 总分
📊

多因子排序 (Factor Ranking)

单一因子（如评分）容易受到极端值干扰。系统采用双因子复合排序：先按评分和波动率分别排名， 再以 3:1 的权重合成综合排名。高分+低波动的股票排名最靠前，体现了"优质且稳定"的选股理念。

score_rank = 按总分降序排名
volatility_rank = 按20日波动率升序排名
combined_rank = 3 × score_rank
+ 1 × volatility_rank
→ 越小越好
🛡️

风控退出机制

买入容易，卖出才是量化系统的核心。系统设置了 4 层退出触发条件，按优先级从高到低执行。 硬止损保护本金，止盈锁定利润，评分衰减清除弱势股，市值毕业让已经不属于小盘的股票退出池子。

优先级 1: 硬止损 → PnL ≤ -20%
优先级 2: 止盈 → PnL ≥ +40%
优先级 3: 市值毕业 → 超出池子 ×1.3
优先级 4: 评分衰减 → 分 <3.5 且 >15天
💰

FIFO 成本追踪

FIFO（先进先出）是标准的持仓成本记账方法。当卖出股票时，系统按最早买入的批次优先消耗， 计算每笔交易的已实现损益。这确保了损益计算的准确性，也支持了后续的买卖配对分析（Round Trip）。

批次A: 买 1000股 @10.00 (3月1日)
批次B: 买 500股 @11.00 (3月15日)
卖出 1200股 @12.00:
→ 消耗A全部: PnL = 1000×(12-10) = +2000
→ 消耗B部分: PnL = 200×(12-11) = +200
→ B 剩余 300 股
📅

eval_date 周归档机制

LLM 评分是资源密集操作（100只股票 × Gemini API 调用），不可能每日执行。系统采用周度评分 + 日度信号模式： 每周六统一评分一次，工作日复用本周评分生成买卖信号。eval_date 统一映射到"上一个周六"， 解耦了源数据日期与评分归档日期。

周六: 刷新LLM评分 → 存入DB
周一~周五: 读取本周评分
+ 实时行情 → 生成信号
eval_date = 任意日期映射到上周六
例: 周三 4/8 → eval_date = 4/5(周六)

100 只小盘股 × Gemini 打分，约 30 分钟

python scripts/s003/refresh_evaluations.py

python scripts/s003/run_daily.py --skip-refresh
