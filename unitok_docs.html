1 / Architecture

1. 系统架构总览

UniTok 将 VQ-VAE 图像重建 + CLIP 语义对齐 + GAN 对抗训练统一到单个 Tokenizer 中，实现生成与理解的双重能力。

MLLM 下游应用架构

UniTok 训练好的 Tokenizer 被三个下游框架复用：Liquid（统一生成+理解）、LlamaGen（自回归图像生成）、LLaVA（视觉理解）。

多码本归一化向量量化器。将特征沿通道拆分为 8 份，各自使用独立码本（4096 词）做余弦相似度最近邻匹配，STE 直通估计反向传播。

Hybrid CNN-ViT 架构。编码器：Stem + MbConvLNBlock + ViT Blocks (GeGLU MLP)。解码器：ViT Blocks + Upsample + InvMbConvLNBlock + InvStem，输出 3 通道图像。

7.1 各组件初始化方式

models/__init__.py — build_unitok() + build_discriminator()

Codebook (码本) uniform(±0.00347) quant.py:70-76 base = 64-0.5 / 36 ≈ 0.00347
Text Encoder CLIP 预训练 / 默认 main.py:74 OpenCLIP Transformer
DINOv2 骨干 预训练 + 完全冻结 discrim.py:124-125 requires_grad=False, 放在 list 中规避 DDP
Disc heads xavier_normal(gain=0.5) disc_init=-0.5 SpectralConv1d 分类头
Xavier 初始化直觉 Xavier 初始化根据层的输入/输出维度自动计算权重范围：std = gain × sqrt(2 / (fan_in + fan_out))。
这样每层的信号方差保持稳定，不会在深层网络中逐层放大（爆炸）或缩小（消失）。
gain=0.5 意味着初始权重比标准值还小一半，让网络刚开始时输出很小，训练初期更平稳。

关键发现：余弦相似度匹配，不是 L2 距离 代码中 features 和 codebook 都做了 F.normalize(dim=-1)，然后用 argmax(f @ codebook.T) 查找。 因为归一化后 ||a-b||² = 2 - 2(a·b)，最小化 L2 距离等价于最大化内积，但实现上更高效。

VQ Loss 分解

vq_loss = β × MSE(sg[ƒ̂], f) + MSE(ƒ̂, sg[f])

     ┌─────────────────┐ ┌────────────────┐
     │ Commitment Loss │ │ Codebook Loss  │
     │ β = 0.25 (较小) │ │ 权重 = 1.0 (较大) │
     │ 更新编码器 → 靠近码字 │ │ 更新码字 → 靠近编码器 │
     └─────────────────┘ └────────────────┘

sg[·] = stop gradient，码本更新力度是编码器的 4 倍 (1.0 vs 0.25)

STE 直通估计器

▶ 前向传播

输入 f → 量化 → 得到离散码字 ƒ̂
输出值 = ƒ̂（真实的量化结果）

◀ 反向传播

假装量化没发生
梯度直接从 ƒ̂ 复制给 f
∂L/∂f ≈ ∂L/∂ƒ̂
// quant.py:93 — 一行实现 STE 的精妙写法
features_hat = (features_hat.detach() - features.detach()).add_(features)

// 展开: features + (features_hat - features).detach()
// ↑有梯度  ↑常数（无梯度）
// 前向值 = features_hat（量化后） 反向梯度 = ∂L/∂features（穿透）
码本利用率追踪 代码用 EMA 追踪每个码字被选中的频率：前 100 次用 α=0.1（快速适应），之后用 α=0.01（平滑稳定）。 利用率指标 = 被选频率 > 0.01/vocab_size 的码字比例。
注意：这只是监控指标，不影响训练（因为默认 le=0.0，熵损失关闭）。

7.4 训练阶段时间线

main.py:119-121 — warmup_disc_schedule & fade_blur_schedule
Phase 1
0 — 0.375 epoch
纯重建 + VQ + CLIP 对比学习。没有对抗损失，让模型先学会基本的编码-量化-解码能力。
Lv = Lnll + 1.0×Lq + 1.0×Lc
Phase 2
0.375 — 0.405 epoch
判别器渐进启动。对抗损失权重从 0 线性增长到 1，同时 blur 增强从强到弱过渡，防止训练崩溃。
Lv = Lnll + Lq + schedule×w×Lg + Lc
Phase 3
0.405 — 1.0 epoch
全损失稳定训练。所有损失全部生效，自适应权重动态平衡重建质量和对抗真实感。
Lv = Lnll + Lq + 0.4×w×Lg + Lc

7.6 自适应判别器权重

trainer.py:130-146 — 基于梯度范数比的动态平衡
// 取解码器最后一层的参数 θ
last_layer = decoder.get_last_param()

// 计算两个损失对该层的梯度范数比
w = ||∂Lnll/∂θ|| / ||∂Lg/∂θ||

// clamp 防止极端值 (gada=1 模式)
w = clamp(w, 0.015, 10000)

// 最终的对抗损失权重
wei_g = warmup_schedule × 0.4 × w

为什么需要自适应 重建损失和对抗损失的梯度量级差异很大。如果固定权重，可能出现：对抗损失主导 → 重建质量崩溃，或重建损失主导 → 图像模糊。 自适应权重让两个损失对 Decoder 最后一层的影响力保持平衡，训练更稳定。

判别器训练时的交替冻结

disc.requires_grad_(False) // 冻结判别器
disc.eval()
Lg = -disc(aug(rec_img)).mean() // 梯度只流向 UniTok

// 计算 Ld（判别器损失）时：
rec_img = rec_img.data // 完全截断梯度
disc.requires_grad_(True) // 解冻判别器
disc.train()
Ld = hinge(real) + hinge(-fake) // 梯度只流向 Disc heads
8 / MLLM Downstream Training

8. MLLM 下游训练

UniTok 训练完成后，其各组件被三个下游框架复用：Liquid（统一生成+理解 MLLM）、LlamaGen（自回归图像生成）、LLaVA（视觉理解）。本章详解各框架如何集成 UniTok 以及其训练机制。

8.1

8.1 UniTok 在 MLLM 中的复用方式

预训练的 UniTok 为下游任务提供三种接口：

框架复用的 UniTok 组件任务类型核心代码
Liquid Quantizer (冻结) + AttnProjection + MM Projector 理解 + 生成 eval/liquid/model/liquid.py
LlamaGen img_to_idx() 离线提取离散码 纯图像生成 eval/llamagen/autoregressive/train/
LLaVA Encoder 作为 Vision Tower 纯视觉理解 eval/llava/llava/train/train.py
关键区别：Liquid 使用离散 token indices作为输入（通过 TokenEmbedder 将码本索引映射回连续特征）， LlamaGen 也使用离散码但在独立的 GPT 模型中训练， 而 LLaVA 使用 UniTok 的连续 encoder 特征（不经过量化）。

8.2 Liquid 统一多模态 LLM

损失函数与训练策略

Liquid 混合损失
Ltotal = α · Ltext + β · Limage
α = Ntext / (Ntext + Nimage)， β = Nimage / (Ntext + Nimage)
Ltext = CE(lm_head logits, text labels)
Limage = CE(ar_head logits, image code labels) + 0.00005 · z_loss
组件是否训练备注
Quantizer (VectorQuantizerM)冻结从 UniTok checkpoint 加载，requires_grad=False，始终 eval()
AttnProjection可训练注意：这里使用 causal attention 版本，非 UniTok 原始的双向版本
MM Projector可训练LayerNorm→Linear→GELU→Linear，将 1024d 映射到 LLM hidden_size
LLM Backbone (Llama)可训练/LoRA完整微调或 LoRA，取决于配置
AR_head可训练3 层 LlamaDecoderLayer + codebook embeddings + linear head
Vision Tower (CLIP)部分可训练optimize_vision_tower=True 时训练后 1/2 层
数据混合：每个 batch 中的样本通过 data_type 字段区分——data_type=0 为理解任务（VQA 等），data_type=1 为生成任务（text-to-image）。 生成任务样本中，<image> token 位置的 hidden states 被提取送入 AR_head 计算图像生成损失。 T2I_ratio 参数（默认 0.5）控制训练数据中生成/理解的比例。

8.4 LLaVA 视觉理解

LLaVA 使用 UniTok 的 Encoder 作为 Vision Tower，提取连续视觉特征后通过 MLP 投射到 LLM 空间，纯文本生成式理解。

两阶段训练流程

Stage 1: Pretrain
目标：对齐视觉-语言特征空间
训练内容：仅 MM Projector (MLP)
冻结：Vision Tower + LLM backbone
数据：558K image-caption pairs
命令：scripts/v1_5/pretrain.sh
关键参数：
--tune_mm_mlp_adapter True
--custom_encoder True
--quantize True
Stage 2: Finetune
目标：指令跟随能力
训练内容：LLM backbone + MM Projector
冻结：Vision Tower (可选部分解冻后半)
数据：665K 多任务指令数据
命令：scripts/v1_5/finetune.sh
关键参数：
--pretrain_mm_mlp_adapter Stage1输出
--custom_encoder True
--quantize True

方面标准 LLaVAUniTok LLaVA

13 / Glossary

13. 核心术语速查

VQ-VAE
Vector Quantized VAE，使用离散码本将连续特征量化为离散 Token。UniTok 的核心范式。
Multi-Codebook
将特征沿通道维度拆分为 N 份，每份使用独立码本量化。UniTok 使用 8 个并行码本，每个 4096 词。
Normalized VQ
码字和编码特征均做 L2 归一化后匹配，等价于余弦相似度最近邻搜索，训练更稳定。
STE (Straight-Through)
前向使用量化后的离散值，反向传播时将梯度直接传给编码器，绕过不可导的 argmax 操作。
CLIP Alignment
通过对比学习使量化后的视觉特征（均值池化 + 投影）与文本特征在共享嵌入空间中对齐。
Adaptive Disc Weight
根据 NLL 损失和 GAN 损失对解码器最后一层的梯度范数比值，自动调节 GAN 损失的权重。
DiffAug
可微分数据增强，对送入判别器的图像（真实 + 重建）做随机变换，防止判别器过拟合。
BCR
Balanced Consistency Regularization，约束判别器对不同增强版本的输出保持一致，提升稳定性。
ViTamin
Hybrid CNN-ViT 架构。前两阶段使用 MobileConv 降采样，第三阶段使用 ViT Transformer blocks。
