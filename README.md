## 文件结构

```
paper_summary/
├── README.md                              # 项目说明与页面索引
├── CLAUDE.md                              # 项目规范（AI 协作指导）
├── meeting_summary.md                     # 会议记录原始文本
├── {year}_{topic_id}.html                 # 页面文件（推荐命名）
└── {legacy_name}.html                     # 历史遗留命名的页面文件
```

## 文件命名规范

**推荐格式**：`{year}_{topic_id}.html`
- `year`：内容对应年份（4 位数字）
- `topic_id`：主题简称（小写，下划线分隔）
- 示例：`2024_locomo.html`、`2025_cad_survey.html`

> **注意**：部分早期创建的文件（如 `SciDiagram.html`、`Artificial_Analysis_Intelligence.html`）未遵循此命名规范。为避免破坏已分享的 GitHub Pages 链接，这些文件暂不重命名。**新增页面必须遵循上述命名规范。**

## 部署说明

本仓库使用 GitHub Pages 从 `main` 分支根目录部署。推送到 `main` 后自动部署。
